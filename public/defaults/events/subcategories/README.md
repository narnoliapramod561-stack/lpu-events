# LPU Events — Subcategory Default Images

Production default images for event subcategories.

- Canvas: 1920×800
- Aspect ratio: 2.4:1
- Format: WebP
- Style: premium, minimal, cinematic LPU Events visual language
- School subcategories are intentionally excluded
- Naming: `<category-key>_<subcategory-key>.webp`

This directory is intended to contain one default image per non-School event subcategory.
